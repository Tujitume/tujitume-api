## Milestones

`POST /applications/{application}/award`, `POST|GET /applications/{application_id}/milestones/templates`, `PATCH|DELETE /milestones/templates/{milestone_id}`, `POST /applications/{application_id}/milestones/activate`, `POST /applications/{application_id}/milestones/submit-plan`, `POST /applications/{application_id}/milestones/request-changes`, and `POST /applications/{application_id}/milestones/revision-feedback`.

Applicants may edit only allowed hybrid template fields before submitting their plan.
